How to use this lab

Start with Git fundamentals, then apply the Delta ticket-to-branch-to-PR workflow. Use support modules only when they help the work in front of you.

1 Start with Visual Branching

Use the local trainer to understand commits, branches, merge, remotes, fetch, pull, and push before the Delta SOP lab.

Visual Branching Trainer
2 Run Ticket-to-PR

Apply the SOP: confirm identity, clone, inspect origin, pull main, branch safely, review the diff, commit, and publish for PR.

Ticket to First PR
3 Build a Project Capsule

Use this after Ticket-to-PR for longer analyst work where durable context, decisions, and workstream files matter.

Project Capsule
4 Use Recovery Drills only as needed

Open the optional drills for wrong-branch, dirty switch, unstaged/staged cleanup, or conflict recovery reps.
