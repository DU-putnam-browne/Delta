Delta translation

The trainer often uses git checkout -b feature/x. In Delta daily workflow, prefer git switch -c feature/x for new branches and git switch main to return to main.

Reset scope

Reset trainer clears only this trainer's local progress. The main lab reset does not clear trainer progress.
