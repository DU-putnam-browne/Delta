# Tool Module Family

Tool modules teach setup and daily use of work tools. They are support modules, not replacements for the Git path.

## Modules

| Module | Purpose |
| --- | --- |
| `codex` | Install/verify Codex, log in, open from a repo root, and use agent assistance safely |
| `vscode` | Open a repo folder, navigate files, edit, review diffs, stage, and commit from VS Code |

## Aha Moment

The tool path lands when the learner can open the right repo, see the same branch/files in the editor and terminal, make a small change, and understand what the tool is showing them.

## Design Rules

- Keep tools connected to real work, not abstract menus.
- Teach setup only to the point needed for productive use.
- Keep terminal, Source Control, Explorer, and file editor concepts aligned.
- Do not upload progress or state anywhere.
- Do not imply Codex or VS Code can bypass review.
